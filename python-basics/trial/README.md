# Python Basics Trial

This folder contains small practice examples for learning Python basics.

Run any file with:

```bash
python3 filename.py
```

Examples included:

- `01_variables.py` - variables, data types, and f-strings
- `02_conditions_loops.py` - if/else, for loops, and while loops
- `03_functions.py` - reusable functions with parameters and return values
- `04_collections.py` - lists and dictionaries
- `05_mini_calculator.py` - a small calculator using input and functions
- `06_oop_theory.py` - class and object theory with a student example
- `07_file_handling_theory.py` - writing and reading a simple text file
- `08_error_handling_theory.py` - try/except examples for common errors
